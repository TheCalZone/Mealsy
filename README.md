# Mealsy Android test build

[Download signed APK](Mealsy-b6590ea-test.apk) for Android 6 or later. Uses the same cloud debug signing key as the previous test builds; allow installation from your browser when prompted. This is a standalone test build, not a production store release.

Source: TheCalZone/Mealsy, branch `codex/android-runtime-fixes`, commit `b6590ea`.

Includes five colour palettes, system/light/dark modes, larger reading text, optional recipe photos, shopping defaults, recipe sorting and screen-awake preferences. Open Settings from the Home or Account toolbar. Preferences save on this device.

123 app tests and the Android build passed; APK signature verified. Actual phone checks remain: [settings guide and checklist](https://github.com/TheCalZone/Mealsy/blob/codex/android-runtime-fixes/SETTINGS.md). Firebase server configuration is unchanged.
